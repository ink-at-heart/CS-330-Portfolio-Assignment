# CS-330-Portfolio-Assignment
Portfolio assignment for CS 330 with the code &amp; Design Document of my finals Project.
<br><br><br>
For this project, I had to choose a 3D scene to recreate with OpenGL. The scene I chose was a forest scene with a sunflower, pine tree, and log cabin. My Design Document file describes how I chose to recreate these objects in the scene. The full zip file of the full project was too large of a file to include so I only included the Solution file in this repository assignment.<br><br><br>
<b>How do I approach designing software? What new design skills has your work on the project helped you to craft? What design process did you follow for your project work? How could tactics from your design approach be applied in future work?</b><br><br>
I like to take a problem-solving approach to designing software. What is your software going to solve or provide to the user? In this case, I was designing a 3D scene program that the user can navigate around and view from different angles. I looked for inspiration pictures online of what I wanted to include in my forest scene, ultimately deciding on the sunflower, pine tree, and log cabin. Then I figured out what shapes I wanted to use to build each object in the scene and sketched out their basic scale and placement in the scene. Before taking this course, I hadn't had any experience with designing or writing code for 3D graphics. I'd taken Linear Algebra before, so I was familiar with the math behind the positioning, scale, etc. but hadn't applied that math and logic to a program before this, which was more of a challenge than I'd thought, but that also made it all the more satisfying whenever I figured it out and got the scene to render/look/move the way I wanted it to. As a software engineer, these new skills will be useful for creating animations and visualizations on future projects in my professional career.
<br><br><br>
<b>How do I approach developing programs? What new development strategies did you use while working on your 3D scene? How did iteration factor into your development? How has your approach to developing code evolved throughout the milestones, which led you to the project’s completion?</b><br><br>
My biggest challenges during this project were the rendering loops I used for the sunflower petals and the log walls of the log cabin, applying textures to some of the objects, and getting the lighting right in the scene. Using a for loop to render the sunflower petals around the seed center allowed me to make sure that the petals were evenly spaced and equally sized. Using for loops to horizontally stack the cylinder logs for each of the cabin walls which made sure that the logs and walls rendered as the same height and size/length. Applying textures to the "ground" plane, pine tree, and log cabin allowed the objects to appear more realistic, and adding lighting to the scene added more visual dynamics and further realism as well. Building each object through the iterations of the Milestones assignments allowed me to focus working on each piece of the scene at a time, building on each other to create the final scene at the end.
